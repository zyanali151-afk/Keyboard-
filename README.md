# Keyboard

A custom full-screen Bluetooth HID keyboard for Android TV.

Built by Zyan Ali / BuiltXStudios.

## What It Does

Turns your Android phone into a real Bluetooth keyboard for Android TV.
No server, no WiFi, no BS. Just Bluetooth HID.

## Why

Existing apps fail because they're generic. This one focuses on:
- Proper Bluetooth HID implementation
- Full-screen dedicated keyboard UI
- Android TV compatibility
- No ads, no bloat
